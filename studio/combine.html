YouTube connection and options
One-time setup (about 5 minutes)
  1. Open console.cloud.google.com, create a project, and enable YouTube Data API v3.
  2. APIs & Services, OAuth consent screen: set it to External and add your own Google account as a test user.
  3. Credentials, Create credentials, OAuth client ID, type Web application. Under Authorized JavaScript origins add the address of this site (the part before /studio/).
  4. Paste the client ID above.

Until Google audits the project, YouTube keeps API uploads private. That is fine here: you switch it to public by hand.
